# Python Portfolio

A collection of Python exercises and projects demonstrating core skills in scripting, OOP, and data analysis (Pandas). This repository is a personal portfolio of small exercises and a final project.

## Contents

- `exercise1.py` — small scripting exercise (run with Python).
- `Exercise2_OOP.ipynb` — object-oriented programming exercises (Jupyter notebook).
- `Exercise3_Pandas.ipynb` — data analysis examples using Pandas (Jupyter notebook).
- `Python_FinalProject.ipynb` — final project demonstrating applied skills (Jupyter notebook).
- `requirements.txt` — Python package dependencies.

## Setup

1. Create and activate a virtual environment (recommended):

```bash
python -m venv .venv
source .venv/bin/activate  # macOS / Linux
.venv\\Scripts\\activate     # Windows (PowerShell or cmd)
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

## Running the code

- To run the simple script:

```bash
python exercise1.py
```

- To view and run the notebooks, open them with Jupyter or VS Code:

```bash
jupyter lab   # or jupyter notebook
```

## Notes

- Notebooks contain explanations, visualizations, and step-by-step exercises.
- If a notebook requires a specific kernel or additional packages, install them via `requirements.txt`.
